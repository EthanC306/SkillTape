A quiet place to review your coursework.

SkillTape is a desktop study app for computer-science classes. Read topic notes, drill yourself with fill-in-the-blank recall, run multiple-choice quizzes, and track progress offline, with no terminal required.

Windows may show a SmartScreen warning because the installer is not code-signed yet. The download is served directly from GitHub Releases over HTTPS.

Built for focused study

Everything in one desktop app: no Docker, no terminal, works offline after install.

  • Learn & fill

    Topic notes as cards. Toggle fill mode to hide key terms and recall them from memory.

  • Quizzes & flashcards

    Multiple-choice drills with explanations, plus front/back flashcards per topic.

  • Spaced repetition

    A review queue tracks what is due, what you are learning, and what is new.

  • Auto-updates

    Installed copies check GitHub Releases on launch and download updates in the background.
